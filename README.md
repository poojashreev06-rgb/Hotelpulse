# HotelPulse — Hotel Booking and Revenue Analysis

## Project Overview

HotelPulse is a data analysis project that explores hotel booking data to identify booking patterns, cancellation behaviour, hotel performance, and estimated room revenue. The project uses Python and Pandas to transform booking data into meaningful business insights.

## Objectives

* Analyse hotel booking patterns and customer behaviour.
* Compare City Hotel and Resort Hotel performance.
* Examine booking cancellations and cancellation rates.
* Investigate the relationship between lead time and cancellations.
* Analyse booking patterns across deposit types and market segments.
* Provide data-driven recommendations for improving reservation management.

## Tools and Technologies

* Python
* Pandas
* Data Visualization
* Google Colab
* Jupyter Notebook

## Key Insights

* City Hotel recorded a higher estimated room revenue contribution than Resort Hotel.
* Resort Hotel guests had a longer average stay duration.
* City Hotel had a higher cancellation rate than Resort Hotel.
* Cancellation rates generally increased with longer booking lead times.
* Online Travel Agents contributed the highest booking volume and had a relatively high cancellation rate.
* Deposit-type patterns require further investigation before making policy decisions.

## Methodology

1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Analysis of hotel performance and estimated room revenue
5. Cancellation analysis by lead time, deposit type, and market segment
6. Business insights and recommendations

## Project File

* `Hotelpulse.ipynb` — Jupyter Notebook containing the analysis, visualizations, findings, and recommendations.

## Important Note

Estimated room revenue is calculated using the average daily rate (ADR) multiplied by the total number of nights for completed stays. This is an estimate and should not be interpreted as verified financial revenue or profit. Operational costs and additional financial data would be required to assess actual profitability.

## Conclusion

HotelPulse demonstrates how Python-based data analysis can uncover useful patterns in hotel booking data. The findings can help identify areas for further investigation and support more informed decisions about reservation management and hotel performance.
